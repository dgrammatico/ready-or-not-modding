# ready-or-not-modding

Ready or Not (Unreal Engine 5) mod sources, load orders and notes.

| Path | What |
|---|---|
| `mods/` | Mod source projects (no built paks) |
| `load-orders/` | Installed pak sets with versions |
| `tools/list_paks.ps1` | List installed paks in load order |
| `docs/notes.md` | Install paths, conflicts, logs |
