# Ready or Not modding notes

- Sources: mod.io (in-game browser) and Nexus Mods. In-game mod.io mods install separately from `~mods`.
- Game updates frequently break paks — after each patch, re-check every mod's version.
- Conflicts: two paks touching the same asset → last alphabetically wins. Check with an unpacker (e.g. FModel) to see which assets each pak contains.
- Logs: `%LOCALAPPDATA%\ReadyOrNot\Saved\Logs\ReadyOrNot.log`.
- Multiplayer: everyone needs the same paks.
