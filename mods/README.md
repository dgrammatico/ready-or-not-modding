# Mods

Ready or Not is Unreal Engine 5. Mods are `.pak` files (plus `.utoc`/`.ucas` for IoStore builds) placed in:

`<game>\ReadyOrNot\Content\Paks\~mods\`

Keep each mod's **source** here (Unreal project assets, configs, notes) — not the built paks. Build with the UE version matching the game and the community modding kit.
